## 统计口径与限制

- 有效响应准确率：正确数/有效响应数；拒答、无法识别、演员名和格式错误均保留在有效响应分母。端到端正确率：正确数/全部计划任务；API失败和未执行计入分母。
- 95%区间为Wilson区间，未调整同角色重复样本间相关性。数据集规模和角色覆盖有限，不代表完整剧集或通用识别能力。
- 接口耗时合计实际HTTP尝试时间，不含限频排队和重试退避；usage只统计服务端返回的数据，不能当完整账单。
- 最终2240条任务由已保存响应离线组合，并补齐替换图所需任务；导入响应不代表新增调用。本次整理报告没有模型API调用。
- 本次GT修订02仅更正3张标签并重评分；原始输入快照和2240条模型响应保留不变，新建评估快照，未重复请求模型。
- 原请求没有逐次图像digest；当前图像副本依据冻结清单核验，哈希并非历史请求时即时记录。原始输入快照、当前评估快照和完整样本清单分别记录哈希。
